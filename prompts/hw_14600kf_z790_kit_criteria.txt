# 任务：i5-14600KF + Z790 大板套装

## 目标
- CPU：Intel Core i5-14600KF（必须 14600KF，不是 14600K、14400F、13400F、13600KF）。
- 主板：Z790 大板（ATX），优先 DDR4 版本；华硕 TUF/ROG STRIX、微星 MAG/MPG Z790、技嘉 Z790 小雕/雪雕/魔鹰等主流型号。
- 形态：板U套装优先（CPU + 主板，最好带原盒、挡板、天线、SATA 线、说明书）；也接受 CPU + 主板 + 32G DDR4 内存打包。
- 价格：1200 ~ 1900 元。
  - 14600KF + Z790 DDR4 大板：1400 ~ 1650 元好价。
  - 带 32G DDR4 3200/3600 内存：1600 ~ 1900 元好价。
  - 低于 1200 元高度警惕假货、坏件、ES/QS、魔改、引流；高于 1900 元溢价。
- DDR5 版本 Z790 也可接受，但必须在标题/描述中明确，价格不超过 1650 元；同等价格优先 DDR4（用户复用老 DDR4 内存）。

## 优先推荐
1. 个人双11升级 15 代/换 AMD 平台出掉的 14600KF + Z790，购买记录、电子发票、原盒齐全。
2. 主板型号写清楚（如 Z790-P、Z790 刀锋、Z790 小雕），有挡板、M.2 螺丝、WiFi 天线、箱说。
3. CPU 顶盖、LGA1700 针脚、主板 CPU 插槽、BIOS 界面实拍，支持个人送保。
4. 支持验货宝/自提验机，卖家主页杂、交易记录自然、描述像真人。

## 一票否决 / 直接 0 分
- B760/B660/H610/H770 冒充 Z790；14600K/13600KF/14400F 冒充 14600KF。
- ES/QS/魔改/开盖/剪角/针脚弯/断针/进水/维修/点不亮/坏件/尸体。
- 只卖盒子、散热器、挡板、空盒、定金、出租、仅展示、价格勿拍。
- 电脑城/装机商/工作室批量出货；“全新组装/支持定制/量大从优/同行勿扰/回收/置换/引流”。
- 价格明显低于市场价且要求加微信/QQ/脱离平台/先款。

## 验货重点
- CPU：顶盖型号 14600KF、LGA1700 针脚、压痕、散片/盒装、保修状态。
- 主板：具体型号、DDR4/DDR5、ATX 版型、CPU 插槽、内存插槽、挡板/天线/箱说、BIOS。
- 凭证：订单、发票、原盒、SN、保修卡；是否支持验货宝/自提。

## 输出提示
- 个人 + 14600KF + Z790 DDR4 型号明确 + 价格 1400~1650 + 凭证齐全：85~95 分，`is_recommended: true`。
- 板U套装但主板型号模糊/无挡板/无凭证：最高 70 分，不推荐。
- DDR5 版本：`risk_tags` 标注“DDR5主板”，价格 ≤1650 可 80 分；>1650 降权。
- 假货/坏件/ES/QS/贩子/引流：0 分，`is_recommended: false`。
