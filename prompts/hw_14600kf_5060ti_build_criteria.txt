# 任务：i5-14600KF + RTX 5060 Ti 整机（目标配置）

## 目标
- 完整主机，核心配置：i5-14600KF + RTX 5060 Ti 8G（16G 可加分）。
- 主板：Z790 DDR4 大板优先；B760M D4 可接受但降权。
- 内存：32G DDR4（16G×2）；主 SSD：1TB 致态/三星 NVMe。
- 电源：750W 金牌全模组（850W 更好）；散热：利民 PA120 SE 双塔或同级；机箱：ATX 中塔。
- 价格：6800 ~ 8500 元；7200 ~ 7800 元好价（不含显示器）；含 2K IPS 显示器可上浮至 8500。
- 仅限个人退坑/升级/搬家；配置单逐项写清品牌型号，有实拍图和购买记录。

## 优先推荐
1. 个人退坑/升级，配置单完整：CPU、主板、显卡、内存、SSD、电源、散热、机箱。
2. 主板 Z790 D4、电源 750W 金牌、显卡 5060 Ti 型号/SN 明确。
3. 京东/天猫订单、电子发票、原盒、保修卡；支持自提验机/验货宝。
4. 主页杂、交易记录自然、描述像真人、能回答硬件问题。

## 一票否决 / 直接 0 分
- 电商整机商、装机商、工作室批量出货，文案模板化。
- “全新组装/支持定制/量大从优/网吧淘汰/回收/置换/引流/仅展示/价格勿拍/定金”。
- 配置单不写主板/电源具体型号，或只写“i5 十四代/5060Ti 显卡/大功率电源/高速固态”。
- 杂牌电源/无 80Plus/瓦数不明；矿卡/网吧卡/维修卡/水洗卡/无 SN。
- 价格低于 6800 元且要求加微信/脱离平台/先款/定金。

## 验货重点
- 逐项核对配置单：CPU、主板、显卡、内存、SSD、电源、散热、机箱。
- 电源品牌型号瓦数、80Plus、是否模组；显卡 SN、防拆贴、GPU-Z。
- 购买记录/发票/保修/原盒；自提烤机/验货宝。

## 输出提示
- 个人 + 14600KF + 5060Ti + Z790 D4 + 32G + 1T + 750W 金牌 + 价格 7200~7800 + 凭证：85~95 分，`is_recommended: true`。
- 缺主板或电源型号：最高 65 分，不推荐。
- 电商整机商/模板化/杂牌电源/矿卡：0 分，`is_recommended: false`。
- 显示器是否包含：在 `reason` 中注明，按含/不含显示器分别判断价格。
