# 任务 2：i5-14600KF + B760M D4 板U套装 / 单U

## 目标商品
- CPU：Intel Core i5-14600KF（必须是 14600KF，不是 14600K、14400F、13400F）。
- 主板：B760M，且必须是 **DDR4 版本**（如微星 B760M MORTAR DDR4、华硕 TUF B760M-PLUS D4、技嘉 B760M 小雕 D4）。
- 搜索关键词：`14600KF B760 D4`、`14600KF 散片`。
- 目标价格区间：850 ~ 1550 元。
- 单 CPU 散片好价：850 ~ 1020 元。
- 搭配华硕/微星 B760M DDR4 主板套装好价：1250 ~ 1500 元。
- 低于 850 元要警惕假货、坏件、针脚弯、无保修或引流。

## 优先推荐（高分画像）
1. 双11升级 15 代/AM5 换下的个人自用 14600KF，原盒/散片均可，但要有购买记录。
2. 板U套装：主板型号明确、DDR4 版本、挡板/箱说齐全、支持个人送保。
3. 卖家主页杂、交易记录自然、描述具体（购买时间、使用场景、升级原因）。
4. 有京东/天猫订单、电子发票、CPU 顶盖照片、主板插槽照片。

## 一票否决 / 直接 0 分
- B660 冒充 B760、B760M DDR5 冒充 DDR4、14600K 冒充 14600KF。
- 主板只写“B760M”不写品牌/具体型号，或图片无法确认芯片组。
- 针脚弯曲、断针、修过、进水、点不亮、坏件、尸体。
- 只卖盒子、散热器、挡板、空盒、定金、出租。
- 价格明显低于市场价且要求加微信/脱离平台/先款。

## 验货重点
- CPU：顶盖型号、针脚（LGA1700）、是否有压痕/弯针、是否散片、保修状态。
- 主板：具体型号、DDR4/DDR5 版本、CPU 插槽针脚、内存插槽、挡板、BIOS 界面、供电散热。
- 凭证：购买记录、发票、原盒、保修卡、SN 码。
- 交易：是否支持验货宝、是否包邮、是否可自提验机。

## 输出提示
- 如果是 DDR5 主板，必须在 `risk_tags` 标注“DDR5主板/非目标版本”，并降权（最高 60 分）。
- 如果是单 CPU 散片、价格 850~1020 元、有购买记录，给 85~95 分并推荐。
- 如果是板U套装、B760M DDR4 型号明确、价格 1250~1500 元，给 85~95 分并推荐。
- 如果主板型号模糊但 CPU 真实，最高 70 分，不得推荐。
