# 任务：1TB NVMe 固态（致态/三星）

## 目标
- 容量 1TB（2TB 若单价合适也可），M.2 NVMe PCIe 3.0/4.0。
- 品牌型号：致态 TiPlus7100 / TiPro7000 / Ti600，三星 990 PRO / 990 EVO / 980 PRO / 970 EVO Plus。
- 价格：500 ~ 900 元。
  - 致态 1TB：≤850 元好价；三星 1TB：≤750 元好价。
  - 2TB：≤900 元神价（按容量折算，型号/健康度优先）。
- 优先个人升级换下、整机拆下，写入量低（TBW 剩余高），有购买记录/发票/原盒。

## 优先推荐
1. 个人升级 2T/4T 换下的 1TB 致态/三星，购买记录/发票/原盒齐全。
2. CrystalDiskInfo 健康度 ≥95%、写入量低、通电时间短。
3. 三星 990 PRO/990 EVO、致态 TiPlus7100/TiPro7000 等主流型号。
4. 支持验货宝/自提，卖家主页杂、描述像真人。

## 一票否决 / 直接 0 分
- 杂牌/山寨/扩容盘/假三星/假致态、QLC 冒充 TLC、无品牌型号。
- 矿盘/写入量巨大/健康度低/通电时间异常、维修/掉盘/点不亮。
- 只卖盒子、空盒、散热马甲、定金、出租、仅展示、价格勿拍。
- 贩子/装机商模板文案、回收/置换/引流、要求加微信/脱离平台/先款。
- 价格明显低于市场价且要求先款。

## 验货重点
- CrystalDiskInfo：健康度、通电时间、写入量、固件、SN。
- 型号/容量/接口/协议；SN 官网保修查询；全盘测速/跑分。
- 凭证：订单、发票、原盒、保修卡；是否支持验货宝/自提。

## 输出提示
- 个人 + 致态/三星 1TB + 健康度 ≥95% + 价格 ≤850 + 凭证：85~95 分，`is_recommended: true`。
- 2TB 价格 ≤900 可给 90 分；型号模糊/健康度不明：最高 70 分。
- 杂牌/矿盘/假货/坏件/贩子：0 分，`is_recommended: false`。
