# 任务：i5-14600KF 无显卡半套机 / 拔卡机

## 目标
- CPU：Intel Core i5-14600KF（必须 14600KF，不是 14600K、14400F、13400F）。
- 主板：B760M，优先 DDR4 版本；华硕、微星、技嘉主流型号。
- 形态：不含显卡的半套主机 / 拔卡机；或 14600KF + B760M D4 + 32G DDR4 + 散热/电源打包。
- 价格：1400 ~ 2500 元。
  - 单 U + B760M D4：1400 ~ 1900 元好价。
  - 加 32G DDR4 + 散热/电源：1900 ~ 2500 元好价。
  - 低于 1400 元警惕假货、坏件、引流；高于 2500 元溢价。

## 优先推荐
1. 个人双11升级、换平台、退坑，描述具体，主页商品杂。
2. 主板型号明确，DDR4 版本，挡板/箱说/购买记录齐全。
3. 32G DDR4 双通道、品牌电源、散热器齐全。
4. 有京东/天猫订单、电子发票、CPU 顶盖/主板插槽实拍。

## 一票否决 / 直接 0 分
- H610 主板；B660 冒充 B760；DDR5 主板（非目标，最高 60 分并标注）。
- 电脑城/装机商/工作室；“全新组装/支持定制/量大从优/网吧淘汰/回收/置换/引流/同行勿扰”。
- 只写“i5 十四代”“B760M”不写具体型号，或图片无法确认芯片组。
- 针脚弯/断针/修过/进水/点不亮/坏件/尸体；只卖盒子/散热器/挡板/定金/出租。
- 价格明显异常且要求加微信/脱离平台/先款。

## 验货重点
- CPU：顶盖型号、LGA1700 针脚、压痕、散片/盒装、保修状态。
- 主板：具体型号、DDR4 插槽、CPU 插槽、挡板、BIOS、供电散热。
- 内存容量/频率/品牌；电源品牌/瓦数；散热器型号。
- 凭证：订单、发票、原盒、SN、保修卡；是否支持验货宝/自提。

## 输出提示
- 个人 + 14600KF + B760M D4 型号明确 + 32G + 价格 1900~2500 + 凭证齐全：85~95 分。
- 主板型号模糊或只有单 U 无凭证：最高 70 分，不推荐。
- H610/贩子/假货/坏件：0 分，`is_recommended: false`。
