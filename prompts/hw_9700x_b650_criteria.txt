# 任务：AMD R7 9700X + B650M 板U / 无显卡半套

## 目标
- CPU：AMD Ryzen 7 9700X（必须 9700X，不是 9700、9600X、7600X、7500F）。
- 主板：B650M，优先微星迫击炮、华硕重炮手、技嘉小雕；A620 降权。
- 形态：板U套装，或不含显卡的半套准系统；可带 DDR5 16G/32G。
- 价格：1800 ~ 3000 元。
  - 9700X + B650M：1800 ~ 2400 元好价。
  - 加 16G DDR5：2200 ~ 2700 元。
  - 加 32G DDR5：2500 ~ 3000 元；总价低于 2700 元为神价。
- 过滤全新电商报价单、装机商。

## 优先推荐
1. 个人升级 9800X3D/AM5 换下，购买记录/发票/原盒齐全。
2. 主板型号明确，B650M，DDR5，BIOS 正常，挡板/箱说齐全。
3. DDR5 16G/32G 6000MHz 双通道；品牌电源/散热。
4. 实拍 CPU 顶盖、AM5 针脚、主板插槽、内存。

## 一票否决 / 直接 0 分
- 9700 非 X、9600X/7600X/7500F 冒充 9700X；A620 冒充 B650。
- 主板只写 B650 不写品牌/型号；针脚弯/断针/修过/进水/点不亮。
- 电商整机商/装机商；“全新未拆/支持定制/量大从优/回收/置换/引流/定金”。
- 价格异常低且要求加微信/脱离平台/先款。

## 验货重点
- AM5 针脚、CPU 顶盖、主板插槽、BIOS、内存插槽、挡板。
- 内存容量/频率/品牌；散热器；电源；机箱。
- 订单/发票/原盒/SN/保修；是否支持验货宝/自提。

## 输出提示
- 个人 + 9700X + B650M 型号明确 + 32G DDR5 + 总价低于 2700：90~100 分。
- 个人 + 板U + 价格 1800~2400 + 凭证：85~95 分。
- 主板型号模糊/A620/无凭证：最高 65~70 分，不推荐。
- 贩子/假货/坏件：0 分，`is_recommended: false`。
